# College Event Feedback Analysis (Power BI)

## Project Overview

This repository contains a **Power BI dashboard** created to analyze **college event feedback** collected from participants. The goal is to convert raw feedback data into meaningful insights that help organizers understand participant satisfaction and improve future events.

The Power BI files provided (`Task 1.pbix`, `Task 2.pbix`) focus on:

* Ratings analysis
* Participant feedback trends
* Overall event performance


## Repository Structure

College-Event-Feedback-Analysis/
│
├── Task 1.pbix                 # Power BI Dashboard file (Ratings & Feedback)
├── Task 2.pbix                 # Power BI Dashboard file (Advanced Analysis)
├── README.md                  # Project documentation
└── screenshots/               # (Optional) Dashboard images



## Key Insights Covered

* Average ratings by event/session
* Distribution of feedback scores
* Participant satisfaction levels
* Best and worst performing areas


## Tools & Technologies

* **Microsoft Power BI**
* **Excel / CSV** (as data source)
* **Data Cleaning & Visualization**


## How to Use

1. Download or clone this repository
2. Open `Task 1.pbix` or `Task 2.pbix` using **Power BI Desktop**
3. Refresh data (if source is connected)
4. Explore the interactive dashboard


## Project Outcome

This dashboard helps:

* Event organizers take **data-driven decisions**
* Identify improvement areas
* Measure overall event success
